## Charged ideal experiment

Fix positive prices c_j and a scalar gate charge g_min. A permitted ideal schedule has batches s with counts k_sj and charged resources A_s,d_s satisfying

```text
sum_s A_s <= G,
sum_s d_s <= D,
sum_j c_j*k_sj <= A_s*d_s,
N <= floor(G/g_min).
```

These inequalities define the charged ideal experiment. Let kappa_j be the source-linked local bad-response densities and put rho=max_j(kappa_j/c_j). For every adaptive schedule in this experiment,

```text
sum_s sqrt(10*sum_j kappa_j*k_sj)
  <= sqrt(10*rho)*sum_s sqrt(sum_j c_j*k_sj)
  <= sqrt(10*rho)*sum_s sqrt(A_s*d_s)
  <= sqrt(10*rho*G*D).
```

The first inequality uses kappa_j<=rho*c_j term by term. The second is the batch charge. The third is Cauchy-Schwarz and the two total budgets. Squaring gives the main-event bound 10*rho*G*D. The published typed finite and collision terms use the same N bound and the single total budget. Denote their complete envelope by E(G,D). The exact v2.1 calculator verifies this envelope and its retained 26-event inventory.

## Resource-aware fixed experiment

Let A(G,D) be all adversaries in the declared physical logical-gate model with actual total gates at most G and actual depth at most D. Include adversarial preprocessing and the queries performed inside verification in these totals. Keep the published advice policy and honest authenticated release setup. This class permits arbitrary implementations of the fixed public permutation and its actual modes. Define the compiler event

```text
BadCompiler = BadAll union MissRep union BadTypedBind.
```

For this same class define

```text
Delta_fixed(G,D) = max(0, sup_A Pr_fixed[BadCompiler(A)] - E(G,D)).
```

An upper bound on this quantity is the event-specific fixed-primitive condition. This is the resource-envelope definition already used in the [fixed Poseidon2b boundary](category-one.md#fixed-poseidon2b-boundary). The event is a compiler failure event. It contains extraction failure, missing representation and typed binding failure. Its definition is independent of the final State-validity event.

## Production lifting theorem

Assume the coupled all-root source/recognizer argument establishes BadState subset BadCompiler for the accepted production roots. Suppose delta bounds Delta_fixed(G,D). Then every A in A(G,D) satisfies

```text
Pr_fixed[BadState(A)]
  <= Pr_fixed[BadCompiler(A)]
  <= sup_B Pr_fixed[BadCompiler(B)]
  <= E(G,D) + delta.
```

The first inequality is the structural all-root conclusion. The second is the supremum over the actual allowed adversaries. For the third, if the supremum exceeds E, its excess is exactly the positive-part expression bounded by delta. Otherwise E itself is an upper bound. This proves the claim in both cases.

Every circuit within the actual budget is already included in the supremum. A cheaper scalar circuit, batch sharing or a different depth tradeoff therefore enters the same fixed-primitive obligation. There is one actual resource budget throughout this lifting step.
