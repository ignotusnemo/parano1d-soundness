# Hosted maintainer review keys

These keys verify maintainer decisions initiated from the private noid.network reviewer interface. The service signs only after the authenticated local administrator identity matches the configured maintainer. The signed decision binds the immutable passive submission, its original pull request commit, the final classification, effects and public reviewer note.

This attestation replaces a separate maintainer Forgejo approval for the hosted one-button review flow. Independent approvals required by a conclusive track remain public Forgejo reviews bound to the original submission commit. Earlier version 1 keys and attestations continue to verify historical GitHub-backed decisions.
