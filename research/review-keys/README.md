# Hosted maintainer review keys

These keys verify maintainer decisions initiated from the private noid.network reviewer interface. The service signs only after an authenticated GitHub identity matches the pinned repository owner. The signed decision binds the immutable passive submission, its original pull request commit, the final classification, effects and public reviewer note.

This attestation replaces a separate maintainer GitHub approval for the hosted one-button review flow. Independent approvals required by a conclusive track remain public GitHub reviews bound to the original submission commit.
