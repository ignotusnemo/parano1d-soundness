# Hosted researcher delegation keys

These public keys verify researcher identity statements created by the hosted noid.network service. A current delegation is accepted only when the pull request author, Forgejo origin and repository match the exact values pinned by the same key descriptor. Version 1 descriptors remain available to verify historical GitHub-hosted delegations.

Possession of a service signing key cannot accept a cryptographic result. It can only bind a noid.network researcher to passive submission bytes. The public verifier, machine contract and any required expert review remain separate.
