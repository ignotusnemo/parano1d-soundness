# Hosted researcher delegation keys

These public keys verify researcher identity statements created by the hosted noid.network service. A delegation is accepted only when the pull request author is the exact GitHub App bot pinned by the same key descriptor. Direct pull requests continue to use their GitHub author and do not contain a delegation.

Possession of a service signing key cannot accept a cryptographic result. It can only bind a GitHub researcher to passive submission bytes. The protected verifier, machine contract and any required expert review remain unchanged.
